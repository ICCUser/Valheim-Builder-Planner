VALHEIM BUILDER PLANNER 1.0.0
Unofficial building planner for Valheim — https://github.com/ICCUser/valheim-builder-planner

HOW TO START
1. Keep this whole folder together (the .exe, the .pck file and the data_ folder).
2. Run ValheimBuilderPlanner.exe (Windows 10/11, 64-bit). Valheim must be installed.
3. On first launch the planner reads the building pieces from YOUR Valheim install (about a minute).
   Nothing from the game is included in this download. Your game and saves are only read, never modified.

CONTROLS (shown at the bottom of the window)
Tab: menu / mouse · Mouse: look · WASD (ZQSD on AZERTY): fly · Space/C: up/down · Left click: place
Wheel or R: rotate · Middle click: remove · Shift+middle click: pick a piece · Ctrl+Z: undo
P: floor view · V: stability · B: rebuild guide

PLANBUILD (OPTIONAL MOD)
Export > PlanBuild blueprint sends your plan to the PlanBuild mod (place it as ghost pieces in game).
While any mod is loaded, Valheim disables achievements. Without mods, the planner is 100 % vanilla.

Your plans, settings and the data read from the game are stored in %APPDATA%\ValheimBuilderPlanner.

FRANÇAIS
1. Garde ce dossier entier (le .exe, le fichier .pck et le dossier data_).
2. Lance ValheimBuilderPlanner.exe. Valheim doit être installé.
3. Au premier lancement, l'outil lit les pièces dans TON installation de Valheim (environ une minute).
   Aucun fichier du jeu n'est inclus. Ton jeu et tes sauvegardes sont seulement lus, jamais modifiés.
La langue se choisit en haut à droite (36 langues pour les noms des pièces ; interface en français et anglais).
Export PlanBuild optionnel : c'est un mod, les succès sont désactivés tant qu'un mod est chargé.
