What it is: a standalone Windows building planner for Valheim (not an in-game mod). It contains an executable because it is a desktop application made with the Godot Engine 4.7 (.NET/C#). The zip contains:
- ValheimBuilderPlanner.exe – the Godot 4.7.2 release export template (official, unsigned)
- ValheimBuilderPlanner.pck – the app's resources and translations
- data_ValheimPlanner_windows_x86_64/ – the app's compiled C# code (ValheimPlanner.dll), the .NET runtime and the AssetsTools.NET library (MIT)
- README.txt, LICENSE.txt, THIRD_PARTY_NOTICES.txt
No game files are included: on first launch the app reads the building pieces from the player's own Valheim install (read-only).

How to build it from source:
1. Install the .NET 8 SDK and Godot 4.7.2 (.NET edition), plus the Godot 4.7.2 export templates.
2. git clone https://github.com/ICCUser/Valheim-Builder-Planner
3. cd Valheim-Builder-Planner/app && dotnet build
4. godot --headless --path . --export-release "Windows Desktop" ../build/ValheimBuilderPlanner.exe
